# Never Get Rejected - Interactive Date Proposal App

An interactive, responsive single-page web application built with **React** and **Vite** that lets users plan a custom date night. This project was inspired by a popular trend on Instagram Reels and recreated from scratch to practice advanced frontend state control and serverless data storage.

## Live Demo
[View Live Project Application](https://never-get-rejected.vercel.app/)

## Features
* A "NO" button that utilizes tracking mathematics (`onMouseMove`) and physics-based CSS transitions to smoothly glide away from the user's cursor.
* Bypassed expensive third-party database platforms by coding a custom **Google Apps Script API** serverless handler to append user choices straight to a private Google Sheet.

## Tech Stack
* **Frontend:** React, JavaScript (ES6+), HTML5, Custom CSS3
* **Build Tool:** Vite
* **Backend Pipeline:** Google Apps Script / Google Sheets API
* **Hosting:** Vercel
