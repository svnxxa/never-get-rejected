# 💖 Never Get Rejected - Interactive Date Proposal App

An interactive, foolproof date planner built with **React** and **Vite**. I saw a viral reel on Instagram where a "NO" button ran away from the user's mouse, and I loved the idea so much that I decided to reverse-engineer it and build my own version from scratch.

## Live Demo
[View Live Project Application](https://never-get-rejected.vercel.app/)

**Note:** This works best on a laptop or desktop computer so you can watch the NO button slide away

## Features
* **Magnetic Fleeing UI:** A "NO" button that utilizes tracking mathematics (`onMouseMove`) and physics-based CSS transitions to glide away from the user's cursor.
* **Smart Dynamic Flow:** A clean, multi-step state wizard that branches pages based on user-selected preferences.
* **Interactive Option Loops:** Dynamic multi-selection tag matrices generated efficiently using JavaScript array mapping (`.map()`) and smart active filtering toggles.
* **Input & Calendar Validation:** Built-in form validation blocks past-date selections and empty fields, guiding users through a foolproof submission flow.
* **Serverless Free Data Pipeline:** Bypassed third-party database platforms by coding a custom **Google Apps Script API** serverless handler to append user choices straight to a private Google Sheet.

## Tech Stack
* **Frontend:** React, JavaScript (ES6+), HTML5, Custom CSS3
* **Build Tool:** Vite
* **Backend Pipeline:** Google Apps Script / Google Sheets API
* **Hosting:** Vercel
